# Target List (Document A)

Master list of companies to run through the agent. Three groups by how you would engage. Every franchise-arm candidate is marked **verify**, because confirming the arm is the agent's first job, not an assumption.

Tags used:
- **Engagement**: `consulting` (CMC partner: scale-up, auditing, strategy), `relationship` (MSL, speaking, branded content), `channel` (distribution / programming), `partner` (ecosystem / referral, not a client).
- **Evidence**: `confirmed` (public paper trail verified), `candidate-verify` (named by you or likely, agent must confirm the arm).
