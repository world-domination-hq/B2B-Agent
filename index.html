BIO CMC Target Agent

A public-facing landing page for the folder-driven RNA / biologics CMC target scouting system.

View features

What this repo does

This project is a research pipeline for finding the CMC-focused business development targets that matter most ahead of BIO.

  • Collect raw company and contact facts into `03_inputs/`.
  • Run the prompt workflow in `02_prompts/` for scoring and briefing.
  • Publish final briefs to `04_outputs/` and export to ClickUp.

How to use it

Start by reading the public build plan and the schema documents, then follow the folder-by-folder workflow.

  • Read `05_Build Plan/build_plan_eli5.md` first.
  • Use `00_Targets/target_list.md` to choose priorities.
  • Gather raw facts and save them into `03_inputs/`.
  • Run `02_prompts/` sequentially and save outputs into `04_outputs/`.

Page structure

  • assets/ holds styles and public graphics.
  • features/ explains the page and system capabilities.
  • index.html is the public landing page.
  • README.md remains the main repo guide.
