# BIO CMC Agent features

This folder explains the public-facing capabilities of the BIO CMC Agent project.

## What it is

- A folder-driven research playbook for RNA / biologics CMC target discovery.
- A no-code prompt workflow using `02_prompts/` and hand-collected raw inputs in `03_inputs/`.
- A scoring and export model designed for ClickUp or spreadsheet import.
- An operations template for BIO conference target preparation.

## What the page includes

- A clean landing page at `index.html` with an overview of the system.
- A reusable `assets/` folder for page styles and logo graphics.
- A feature summary for public readers.
- A link to the step-by-step build plan and folder map.

## Built for public sharing

The page is designed for a public repository audience:

- explain the workflow clearly,
- surface the folder structure,
- show the minimum steps to run the system,
- keep sensitive raw research out of the page.

## Core benefits

- makes the project easier to understand at a glance,
- gives stakeholders a simple entry point,
- keeps the repo structure visible and usable,
- supports later GitHub Pages or static site publishing.
